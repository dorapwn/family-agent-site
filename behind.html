一、影網頁：headless browser 係咩？

你喺 學業指南 或者 玩樂指南 見到嘅網頁截圖，唔係智能體自己畫嘅，係智能體幫你開一個真嘅瀏覽器， 去嗰個網址影張相。

「headless」係咩意思？

瀏覽器（Chrome、Safari、Edge）開一個網頁，正常情況你見到個視窗。 但伺服器上面嘅電腦冇屏幕，根本唔需要開個視窗出嚟—— 只需要個程式將網頁「讀入去」然後畫成圖。

Headless browser 意思就係淨係用瀏覽器嘅引擎，唔開視窗。

點解要咁做？
  • 你可以直連原文（hkeaa.edu.hk），唔使經過任何中途網站
  • 網站日後改咗，你張圖唔會變——因為張圖已經存咗喺呢度
  • 有啲網站會擋自動瀏覽器。呢種情況智能體會話你知， 唔會攞張殘缺嘅圖充數

二、網頁本身

呢四頁指南（加呢頁）全部係智能體寫嘅 HTML。 流程好簡單：

有四道自動檢查

每次 publish 之前，會有四個自動檢查跑一次， 任何一個唔過就唔會 publish：

  1. 每一頁有冇漏咗連結（全部頁要互相連得通）
  2. 所有圖片、影片檔在唔在
  3. SVG 檔格式對唔對（防止畫唔出嚟）
  4. 冇殘留嘅 Markdown 符號（`**`）—— 呢樣捉過我一次
  5. 冇用文字砌出嚟嘅流程圖（流程圖一定要用 SVG）
第 4 個檢查捉過我： 我寫頁嗰陣喺一個格仔入面用咗 `**出嚟嘅嘢**`， Markdown 嘅粗體寫法喺 HTML 入面會原樣顯示出嚟， 讀者會見到兩個星號。所以加咗自動檢查， 唔準再犯。

三、點解唔直接叫智能體畫圖片同影片？

呢個係好多人都會問嘅問題： 「你叫智能體畫張相出嚟啦，點解要畫 SVG？」 答案係：智能體識畫圖片同影片， 但呢部機冇開呢個功能，原因係貴。

其實個功能係存在嘅

Hermes 本身有官方嘅圖片生成同影片生成功能（插件）， 接到 FAL.ai 呢類服務度。配置檔入面其實有齊晒所有選項：

做圖片做影片
deepinfra、fal、krea、meta-ai、openai、openai-codex、openrouter、xai deepinfra、fal、openrouter、xai

但係喺呢部機上面，呢啲全部都停用咗。真正嘅開關係配置檔入面 disabled_toolsets 呢一段 —— 佢列明咗 image_gen、video_gen、video、 tts 全部停用， 而且個配置檔完全冇 image_gen: 同 video_gen: 呢兩段， 即係連幾多錢、點樣計、邊個模型都冇填。

睇相同整相係兩回事。 vision（vision_analyze）冇被停用 —— 所以智能體睇得出你傳過嚟嘅相， 但整唔到新嘅相或者影片。

影片係按秒數計，貴好多。 同一個 FAL 服務上面，影片嘅實際收費大概係 Wan 2.5 $0.05 / 秒、Kling 2.5 約 $0.07–0.08 / 秒、 Veo 3.1 由 $0.20 / 秒起。 即係一條 5 秒嘅短片，差唔多係 $0.25 至 $1，仲要等 25–60 秒先出。

成本同時間都係按次累加 —— 屋企三個人一日傾幾十個對話，唔可能次次都去買圖。

所以點解唔開？

呢個係錢嘅問題，唔係技術問題。 智能體識做，但每做一次都要畀錢。 呢家人嘅用量計劃本身每五個鐘清零一次（見 常見問題），已經要留意外， 唔想再疊多一層按次收費嘅開支。

反而 SVG 係零成本：

SVG / ASCIIAI 生成圖片影片
一次成本$0（淨係計電腦時間）$0.03–$0.65 起
要等即開即有（ASCII 影片約 4 分鐘）圖 1–60 秒，影片更耐
改一個名改一行字要再買一次
放大唔會花會花（位圖有限解像度）
可唔可以自己改得，係文字檔唔得
一句總結： 唔係智能體做唔到，係唔想每張圖都畀錢。 SVG 呢條路行得通、零成本、改得郁，所以行呢條。

如果將來管理員開咗圖片生成，呢啲比較就會變 —— 但到時 SVG 仍然有佢自己嘅位置（圖表、流程圖、動畫，呢啲 AI 未必畫得出嚟）。

四、許願表：表格點樣送得到

你可能會問：GitHub Pages 淨係得啲檔案，表格填完送去邊？

答案：GitHub Pages 收唔到表格。 Pages 只係放 HTML、圖片、CSS 落去俾人睇， 冇伺服器可以接收你撳「送出」嗰一下。 呢個唔係壞咗，係 Pages 本身設計咁。

所以表格唔會「自己送去」。佢改為做一件事： 砌好一句說話，然後叫醒 Telegram。 Telegram 開一個對話，訊息已經幫你打好， 你撳個 send 就真正送到。

管理員可以再簡化一步： 如果話得返智能體個 Telegram 名（唔使 @），加落 <html data-telegram-bot="名">， 按落去就會直接開智能體個對話， 唔使喺分享選單度返揀。
