Telegram 係咩？

如果你有 WhatsApp，就當 Telegram 係同一類嘢：

WhatsAppTelegram
傾偈（私人訊息）傾偈 ✓ 一樣
開群組開群組 ✓ 一樣
傳相、傳檔傳相、傳檔 ✓ 一樣
傳語音訊息個 app 支援發語音 ✓（但智能體仲未開通語音輸入）
打電話、視像通話有，但唔係重點
其實三個分別：
  • 通常行得快啲、慳電腦啲
  • 完全免費，冇廣告
  • 檔案傳輸唔使限大小，所以傳大份 paper 都得
一件要講清楚：你唔使自己開 Telegram 帳號再搵智能體。 管理員已經幫你 setup 好，你只係裝 app 然後登入就得。

Android

  1. 開 Google Play
  2. 搜「Telegram Messenger」
  3. 認住開發者名 —— 係 Telegram FZ-LLC， 唔好裝錯（有一堆假冒嘅）
  4. 撳「安裝」
  5. 開 app，用手機號碼登入
  6. 收一個 verification code，輸入落去

iPhone / iPad

  1. 開 App Store
  2. 搜「Telegram Messenger」
  3. 開發者名同樣係 Telegram FZ-LLC
  4. 撳「取得」→ 可能要撳「以 Face ID 確認」
  5. 開 app，用手機號碼登入（要加國碼 +852）
  6. 收 SMS verification code，輸入落去
iPhone 用 Face ID 登入嘅話，SMS 會自動輸入，唔用手動打字。 冇收到就撳「重新寄送」等十分鐘。

電腦（網頁版）

如果你想喺電腦上面用（返工嗰邊可能會方便啲）：

  1. 開瀏覽器，去 web.telegram.org
  2. 輸入手機號碼（+852 開頭）
  3. 撳「下一步」，用手機上嘅 Telegram 確認 —— 或者收 SMS code 輸入
  4. 完成。對話會同手機同步
電腦版會同手機同步。 唔係另一個智能體——同一個，只係多一個畫面。 手機講咗，電腦即刻見到。

點搵智能體

登入之後，管理員會發一個連結畀你，或者直接加你做聯絡人。

點開個連結，就會見到智能體嘅對話。講嘢就得。

唔見到？ 兩種可能：
  • 仲未有人加你 —— 搵管理員，講明你係邊個（學生 / 屋企人 / 返工）
  • 加咗但搵唔到 —— 對話 list 拉落去搵，智能體名通常係英文

打字定講嘢？

暫時要打字。 語音功能仲未開通。

如果打字對你嚟講太慢，請喺 許願清單 出聲（或者直接同智能體講）， 講明邊個想用語音。開通之後會通知你。

安全提示

  • Telegram 係免費嘅，唔會有人要求你付款或者話係「官方」要你畀錢
  • 唔好將驗證碼（verification code）俾任何人， 包括話係「客服」嘅人
  • 你可以喺 Telegram 兩條直線（Settings → Privacy）set 最後上線時間

仲有問題？

直接問管理員。以下呢啲係技術問題，智能體幫你答：

  • 「我裝咗但登入唔到」
  • 「我搵唔到智能體」
  • 「我可以同時用手機同電腦嗎」
