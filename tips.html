一、畫圖：SVG

學業指南 入面嗰張分數趨勢圖， 唔係用畫圖軟件畫——係智能體直接寫成代碼， 每一條線、每一個點、每一個字都由文字描述。

呢個格式叫 SVG。佢最大嘅優點係 放大都唔會模糊， 所以印出嚟貼喺雪櫃、擺喺學校報告都仲係清楚。

改圖唔使重畫

因為佢係代碼，智能體可以只改其中一兩行。 你講「深啲」、「加多一條⋯⋯」，佢改完即刻 publish， 但個網址唔變。

「用我今次嘅分數畫張趨勢圖」
「畫張圖，深色啲，紙張底色」
「加多一條平均線」

二、短片：ASCII 動畫

主頁頂部嗰條 20 秒嘅動畫，做法同 SVG 類似，都係寫代碼出嚟。

點解字可以郁？

詳細講：

  1. 用數學算出一個「亮度地圖」—— 每一格該著幾多光（0 到 1）
  2. 亮度越高，就配一個更實心嘅符號 （空格 → . → o → @ → 實心方塊）
  3. 貼上顏色（每個場景有唔同色系）
  4. 加掃描線、halo（光暈）、雜訊、邊緣變色，做出舊 CRT 螢幕感
五個場景，五種唔同花色：
  • 學業 — 青綠色，符號向下流動，似答題時嘅感覺
  • 家務 — 琥珀色，一圈圈擴散，似屋企嘅暖光
  • 工作 — 鋼藍色，橫掃線，似報表
  • 玩樂 — 紫紅色，扭動嘅曲線，純粹亂郁
  • 尾 — 四種疊埋一齊，四個人變成一個腦

全部 480 格係平行計，同時跑，大概 4 分鐘出片。

原始碼喺 GitHub 上面。 想改顏色、改節奏、改符號——改幾行數就得。

「做段 ASCII 動畫，講⋯⋯」
「用洋紅色，郁慢啲」

三、會郁嘅 SVG：復古街機排行榜

SVG 唔止可以畫圖，仲可以郁。 下面呢個「星光大道」就係一個 SVG 檔案， 入面寫住幾行指令叫佢自己捲動。

同 ASCII 動畫有咩唔同？

ASCII 動畫會郁嘅 SVG
點樣整 逐格計 480 次，砌成一段影片 寫幾行指令叫佢郁
幾大 一個幾 MB 嘅影片檔 一個幾 KB 嘅文字檔
幾耐先出 計四分鐘 即開即有
改一個名 要重跑成條片 改一行字就得
所以邊樣好？ 兩個都有用。想要似真嘅老遊戲，用 ASCII 動畫。 想要自己改、快、檔案細，用會郁嘅 SVG。 呢個排行榜就係後者。

想改成自己嘅？

直接同智能體講就得，唔使識寫代碼：

「將排行榜啲名改成屋企人嘅名，分數改返真實分數」
「整多一個排行榜，變成學校運動會」
「呢個 SVG 慢啲／快啲」
唔想郁？ 唔使問，已經自動停。 如果你部手機開咗「減少動態效果」（慳電模式）， 呢啲圖就會定喺一格，淨係睇唔郁。

四、做一套簡報：學生會投票指南

上面三招都係畫圖。想做一套可以撳箭嘴逐頁睇嘅 簡報？做法一樣——每一頁都係一個 SVG 檔案， 用 JavaScript 控制邊頁顯示。

1 / 7 方向鍵 / 空格 / 左右掃

每頁係點樣整出嚟？

每頁 SVG 都係一個檔案，內容分三部分：

  • 相 —— 用瀏覽器影低嘅真實網頁截圖， 直接用 <image> 放落去
  • 字 —— 標題、項目、清單，全部係 SVG 文字
  • 框 —— 邊框、色塊、圓角，<rect> 畫

因為三樣嘢都係代碼，所以想改個標題、改個相、改個顏色， 全部都係改幾行字。

個相係真嘅。 呢套簡報入面每張相，都係用瀏覽器實際開咗學生會網頁影落嚟， 唔係搵出嚟嘅 stock 相。 影相嘅步驟寫成咗一個 Python 檔案（capture_su.py）， 隨時可以重影過。

簡報上面嘅資料係幾時查？

2026 年 10 月 24 日，用瀏覽器逐頁查過 學生會網站。 例如「82 個社團」係數學生會自己個社團下拉名單得返嘅 （83 項入面有一項叫 test Society，係測試用嘅）， 六大分類亦係網站自己嘅標題。 唔係估嘅。

資料會變。 社團數目、選舉職位、規則都可能改。 投票之前最好自己再睇一次學生會網站。

要自己整過？

「幫我整一套簡報，講⋯⋯，用 SVG 做」
「呢套簡報加多一頁，講⋯⋯」
「簡報每頁加個頁碼／改個主題色」

問題點解點解決

點解唔直接叫智能體畫張相出嚟？

呢個問題幾多人會問。 答案好簡單：因為畫圖片、畫影片要錢，SVG 唔使。

智能體識畫，唔過就係冇開呢個功能。 有一啲服務專門做呢樣，每畫一張相、每做一段片都要收錢 —— 一張相由幾毫美金到幾毫美金都有，一段影片仲貴好多。 呢家人唔想每次傾偈都花錢，所以唔開。

而且 SVG 好唔同：

  • 零成本 —— 淨係用電腦時間
  • 即開即有 —— 唔使等
  • 自己改得 —— 改一個名唔使再畀錢
  • 放大唔會花
