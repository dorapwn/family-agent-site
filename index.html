呢個網站點樣起上嚟

助理識寫網頁、識將網頁 push 上 GitHub。GitHub 一收到更新，就自動 build 同 publish。 所以流程好簡單： 

你同助理講
    ↓
助理寫 HTML + Markdown
    ↓
git commit  →  git push
    ↓
GitHub Actions 自動 build
    ↓
GitHub Pages publish  ← 你而家睇緊呢版

上面條片亦係同一個道理，只不過多一步：助理先寫一段程式， 用數學算出每一格文字應該係乜，再砌成 MP4。 原始碼喺 GitHub 上面，隨便你睇。 想知中間發生咩事，去 幕後：呢啲圖同片係點做出嚟。
